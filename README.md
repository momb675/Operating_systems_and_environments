## О дисциплине

Курс посвящён практическому освоению операционной системы Linux (на примере Debian):
работа с файловой системой и поиском, управление процессами, справочная система `man`,
базовые команды оболочки, настройка сети в виртуальной среде и работа со снимками
виртуальной машины. Все задания выполняются в консоли и оформляются в виде отчётов
с иллюстрациями (скриншотами терминала).

## Содержание домашних заданий

### 1. Снимки виртуальной машины (`17_09`)
- Подготовка установочного образа Debian и создание учебной ВМ в VirtualBox.
- Сохранение исправного состояния системы в первом снимке (snapshot).
- Моделирование учебного сбоя, завершение работы ВМ.
- Возврат к сохранённому снимку и проверка нормальной загрузки Debian.
- **Ключевые команды:** `whoami`, `hostname`, `cat /etc/os-release`, `journalctl`, `uptime`, `date`.

### 2. Поиск файлов и фильтрация содержимого (`18_09`)
- Поиск файлов по расширению `.log` и сортировка объектов `/usr/bin` по размеру.
- Просмотр источников пакетов APT и фильтрация `/etc/passwd` по подстроке `root`.
- Исключение закомментированных строк из `/etc/services`.
- Поиск объектов `.conf`/`.conf.d` в `/etc`, ограничение глубины поиска.
- Отбор обычных файлов с владельцем `root`, поиск файлов, содержащих слово `root`.
- **Ключевые команды:** `find`, `grep`, `sort`, `head`, `tail`, `2>/dev/null`.

### 3. Процессы и справочная система (`20_09`)
- Отображение иерархии процессов (родительские/дочерние задачи).
- Фильтрация процессов по владельцу, сортировка по расходу памяти.
- Проверка фоновых задач текущей оболочки.
- Работа со справкой: сохранение атрибутов при копировании, поиск страниц `man` по описанию.
- **Ключевые команды:** `ps -ejH`, `ps -eo`, `ps aux --sort=-%mem`, `jobs`, `man -k`, `man`, `grep`, `head`.

### 4. Использование простых команд (`23_09`)
- Создание каталога `work` в домашнем каталоге, проверка абсолютного пути.
- Создание файла `file.txt` (`touch`), запись двух английских абзацев (`printf`).
- Переименование файла в `book.txt`, чтение содержимого.
- Отбор строк со словом `were` в отдельный файл, объединение файлов.
- Подсчёт количества символов `n` с помощью `grep` и `wc`.
- **Ключевые команды:** `mkdir -p`, `cd`, `pwd`, `touch`, `ls -l`, `printf`, `mv`, `cat`, `grep`, `wc`.

### 5. Администрирование 2: возвращение сети (`30_09`)
- Добавление сетевого адаптера Host-Only в VirtualBox.
- Просмотр интерфейсов и IP-адресов (`ip address`).
- Ручное назначение адреса `192.168.56.10/24` интерфейсу `enp0s8`.
- Проверка доступности в обе стороны с помощью `ping` (из Debian и из Windows).
- **Ключевые команды:** `whoami`, `hostname`, `ip -brief address`, `ip address add`, `ping -c 4`, `ip route`, `ip neigh`.
